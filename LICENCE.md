## 🧩 About

**ARK Survival Mod Menu** is a curated list of ARK Survival open-source tools:

- **Overlays** — on-screen helpers, layout notes, resource tracker, spawn map notes
- **Quality-of-Life Helpers** — tame catalog, stat planner, config notes
- **Research Notes** — base layouts and configuration notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Spawn Map Notes — mark resource and creature nodes on the map
- Stat Planner — plan level allocations for study
- Tame Catalog — browse creature stats and taming notes
- Playback Notes — review single-player session logs

### Wallhack
- Item Catalog — browse items, skins, and colors
- Custom Skin Notes — organize cosmetic presets
- HUD Notes — cleaner on-screen information layout

### Aimbot
- Base Planner Notes — segment study on any layout
- Structure Grid Notes — align building placement in the editor
- Resource Tracker — track gathered materials in single-player
